# Repositório de Estudos e Exercícios

Este repositório contém uma coleção de exercícios e projetos desenvolvidos para fins de aprendizado e prática de programação.

## Estrutura do Projeto

O repositório está organizado nos seguintes diretórios principais:

- **Duck/**: Projeto relacionado a um sistema de simulação de patos (Duck).
    - [Projeto_Lagoa/](cci:7://file://wsl.localhost/Ubuntu/home/ivys/Github/apsii/Duck/Projeto_Lagoa:0:0-0:0): Implementação do projeto de simulação de lagoa com patos.

- **Exercicio1/**: Primeiro exercício prático.
    - Projeto Java com estrutura Maven
    - Inclui arquivos de configuração padrão do Maven

- **Exercicio2/**: Segundo exercício prático.
    - Estrutura similar ao Exercicio1, contendo um projeto Java Maven

- **PizzaFactory/**: Projeto de fábrica de pizzas.
    - Implementação de um sistema para gerenciamento de pedidos de pizza
    - Segue o padrão de projeto Factory

## Pré-requisitos

- Java JDK 11 ou superior
- Maven 3.6.3 ou superior
- Git (para clonar o repositório)
